# xclient-pc

X CLIENT — Counter-Strike 1.6 (PC) uchun bitta `XClient.exe`.

`XClient.exe` ishga tushganda:
1. kerak bo'lsa o'zini `C:\Games\XClient` ga o'rnatadi va yangilanishlarni yuklaydi;
2. o'yin yo'q bo'lsa asl CS 1.6 ni o'rnatadi;
3. `xc_theme/` dagi X CLIENT dizaynini (menyu, fon, ranglar, logo) o'yin papkasiga qo'yadi;
4. `cstrike.exe` ni to'g'ridan-to'g'ri ochadi — alohida launcher oynasi yo'q.

Dizayn fayllari: `theme/` (o'yin papkasi tuzilishida, masalan `theme/cstrike/resource/GameMenu.res`).
Eski Electron oynasi (`ui/`) olib tashlandi — kerak bo'lsa git tarixida bor.
